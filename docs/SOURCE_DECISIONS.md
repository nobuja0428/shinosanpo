# 情報源と判断

## 採用したもの

- 既存公開サイトから確認可能だった、3エリア・3コース・6スポット・3読み物の基礎データ
- 既存のAI生成WebP画像16点
- 施設、鉄道事業者、自治体、商店街等の公式URL

## 採用しなかったもの

- 旧コード、旧設定、旧Git履歴
- 旧URL、旧basePath、旧ハッシュルーティング
- 旧GitHub Actions
- 終了済みまたは確認日が不足するイベント
- 閲覧数、ランキング、口コミ、広告実績
- 未確認の営業時間、価格、混雑、現地体験

## 表示上の扱い

- 現地取材は全件未実施
- 公開情報を参照したことと参照先を信頼パネルへ表示
- AI画像はaltだけでなく、画像上ラベルとfigcaptionにも「イメージ」を表示
- 変化しやすい情報は断定せず、公式ページの当日確認を案内
