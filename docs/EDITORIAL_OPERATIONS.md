# 編集運用

## 公開前

1. 公式URLと確認日を記録
2. 断定表現を公式情報の範囲へ限定
3. 現地取材の有無を設定
4. AI画像には「イメージ」を設定
5. `npm run validate:content`
6. `npm run test:all`

## イベント

開始・終了日時、公式URL、確認日が揃ったものだけを公開します。予定、開催中、終了、中止、延期、更新待ちを分けます。終了後は予定枠から除外し、カレンダー追加の対象外にします。

## 修正

更新日、確認日、変更理由を更新します。営業時間・価格・交通・トイレ等は現地または公式情報で再確認し、確認できない場合は更新待ちへ戻します。

## 問い合わせ

連絡先と受信運用が設定されるまで、フォームと送信ボタンを表示しません。設定時は収集項目、保存期間、削除方法を先に決定します。
